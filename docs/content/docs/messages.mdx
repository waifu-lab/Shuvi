## UserMessage

```python
from shuvi.types import UserMessage

UserMessage(content=[
    {"type": "text", "text": "這是什麼？"},
    {"type": "image_url", "image_url": {"url": "data:image/png;base64,..."}},
])
```

```python
AssistantMessage(content="了解。")
```


## 自訂訊息

存進 ContextManager，但不送給模型：

```python
from pydantic import BaseModel


class Memo(BaseModel):
    role: str = "memo"
    content: str


cm.append(Memo(content="使用者今天心情不好"))
```

要讓模型看到，見[自訂轉換](/docs/context#自訂轉換)。
