title: 迴圈控制
---

## 使用

```python
from shuvi.types import LoopConfig

agent = Agent(AgentConfig(provider=llm, loop=LoopConfig(max_inner_iterations=10)))
```

## 次數上限

```python
LoopConfig(
    max_inner_iterations=None,    # 最多呼叫模型幾次，None 是不限
    max_outer_retries=3,          # 驗證沒過最多重來幾次
    max_turn_retries=1,           # 串流斷線重試次數
    max_empty_retries=1,          # 模型空回應重試次數
    max_length_continuations=2,   # 回答被截斷時最多接寫幾次
)
```

## 自訂提示

```python
LoopConfig(
    length_continuation_prompt="你的回答被截斷了，請從斷掉的地方繼續。",

    verify_retry_prompt="還不行。原因：{reason}。請修正後重新回答。",
)
```
